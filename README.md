# CharacterCut AI — Windows download

Download the Windows desktop app from the latest release.

[Download CharacterCutAI-Windows.zip](https://github.com/yashmmmmsksksk/ai-character-cut/releases/latest/download/CharacterCutAI-Windows.zip)

## Install

1. Download and extract the entire ZIP folder.
2. Double-click `CharacterCutAI.exe`.
3. Keep the app window open while you use it.

Video processing runs locally on your Windows PC. The package includes FFmpeg, OpenCV, and face models. The ZIP is about 133 MiB.
